# Career Path Analyser - Final Year Project

Career Analyser is an interactive career path analysis system that helps users understand their current skills, compare careers, and receive structured guidance for bridging skill gaps. The system is designed to make career planning clearer by combining skill analysis, visual charts, and personalised recommendations in one web application.

## Project Overview

The application allows users to select or explore a target career path and view an analysis of the skills required for that role. It compares the user’s current skills with recommended skills, highlights missing areas, and presents a step-by-step learning path to support career development.

This project was developed as a final year project to demonstrate how technology can support career guidance, skill evaluation, and personalized learning recommendations.

## Key Features

- Career path analysis based on selected roles
- Skill gap identification between current and required skills
- Visual dashboards using charts and progress indicators
- Recommended skills and improvement areas
- Step-by-step learning timeline
- Salary progression and career overview insights
- User-friendly interface for career exploration
- Responsive design for desktop and mobile screens

## Technologies Used

- Frontend: HTML / CSS / JavaScript
- Backend: PHP
- Database: MySQL
- Charts: Chart.js
- Version Control: Git and GitHub
